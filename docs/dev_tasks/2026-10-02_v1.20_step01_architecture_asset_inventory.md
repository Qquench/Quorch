#### 【分步改造指引】
1. **仓库根发现与扫描骨架**：`discover_repo_root` 上溯命中 `REPO_ROOT_MARKERS` 即返回，耗尽 `raise RuntimeError`。`scan_modules` 仅用 `ast.parse` 静态解析 `SERVER_ROOT_REL` 下 `.py`；跳过 `SKIP_DIR_NAMES`、symlink 目录（不递归跟随）与 `> MAX_SCANNED_FILE_BYTES` 的文件，**且必须把被跳文件 `(rel_path, size)` 记入 `skipped_files` 并在产物登记**。顶层符号覆盖 `ClassDef` / `FunctionDef` / `AsyncFunctionDef` / `Assign` / `AnnAssign`。
2. **消费者反向索引**：以 `imported_symbols` 建反向映射，扫描根严格取 `CONSUMER_SCAN_ROOTS`；`test_refs` 为路径前缀含 `test` 的子集，`doc_refs` 为 `DOC_ROOT_RELS` 子集；任一为空渲染 `NONE`。每条 `ConsumerEdge.is_lower_bound` 恒为 `True`，产物须以固定文案声明「本图谱为下界，不覆盖 `mod.sym` 属性式访问与运行时反射」。
3. **MCP 契约快照**：解析 `server.py` 中 `@mcp.tool` 装饰函数，抽取 `registered_name`、`name=` 覆盖值、参数名与默认值源码表示（无默认 → `None`）、以及返回注解源码表示。`g1prime_gaps` 固定登记「状态跃迁维度不可由静态 AST 机械推导」，供 roadmap §1.3 在后续 step 补齐。
4. **审计遥测采集**：流式解析 `VERDICTS_REL`，全量计数至 `MAX_TELEMETRY_BYTES`；超限时丢弃首个行并置 `truncated=True`；统计 `reason` 字段频次。`samples < TELEMETRY_MIN_SAMPLES` 时渲染 `INSUFFICIENT SAMPLE (n=…)`。文件缺失/为空/末行损坏 → 平稳降级为空映射 + `telemetry unavailable`，严禁抛异常。
5. **判定与渲染**：对每个符号输出 `消费者数 / 测试引用数 / 文档提及`。分类硬优先级：命中 `MUST_NOT_REMOVE_SYMBOLS` → 强制进入 `must_not_remove`；其余零消费者且零测试/文档引用者进入 `removal_candidates`。
6. **遥测段与 `--check` 解耦**：产物末尾以 `TELEMETRY_BEGIN/END` sentinel 包裹遥测与 `telemetry_meta`；`--check` **仅**比对 sentinel 之外的主体，sentinel 内差异不计入漂移。
7. **写入**：统一 `open(..., "w", encoding="utf-8", newline="\n")`，保证 CRLF 工作区下产物恒为 LF。
8. **单测**：在 `plugins/quench-dev-tasks/server/tests/test_asset_inventory.py` 编写 14 项确定性断言。

#### 【防御与边缘校验】
- **`--check` 零假红（双维度）**：① 同输入连续两次渲染逐字节相同；② **新增一条 verdicts 记录后 `--check` 仍返回 `EXIT_OK`**。
- **纯静态 AST 解析**：AST 断言 `scripts/asset_inventory.py` 的 import 集合 ⊆ `sys.stdlib_module_names`；并断言不出现任何 `fastmcp` / `quench` 前缀导入。
- **CRLF 跨平台保护**：统一 `newline="\n"`；单测断言产物字节中不含 `b"\r\n"`。
- **符号链接防环**：遇 symlink 目录不递归，防止死循环。
- **容错降级**：`verdicts.jsonl` 缺失、为空或末行截断时回退空映射，严禁崩溃。
- **遥测段非门禁**：sentinel 内内容不参与 `--check` 字节比对。
- **分类硬优先级**：`MUST_NOT_REMOVE_SYMBOLS` 覆盖一切统计信号。
- **只读取证铁律**：本任务绝不改动任何生产代码；`dev_tasks_complete` 时 `reconcile_workspace_against_whitelist` 必须零异常通过。
