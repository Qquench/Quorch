6. **规范序列化与路径基准钉死 [E4]**：`json.dumps(obj, sort_keys=True, ensure_ascii=False, separators=(",", ":"))` + 单尾随 `\n`，UTF-8 无 BOM / LF；`scope_report()` / `entries` / `MERGED_EXPANSION_ALLOWLIST` 的相对路径统一钉死为 **plugin 根相对 POSIX 路径**（`server/...`、`hooks/...`）；比较前统一 `canonical_bytes()`；
