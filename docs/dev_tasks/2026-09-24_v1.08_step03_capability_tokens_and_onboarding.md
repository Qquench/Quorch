#### 【缺陷根因与修改目标】
```
【根因分析】
在双宿主架构中，Reviewer 进程拥有与 Runner 相同的 FastMCP 工具清单。
v1.08 原方案（QUENCH_CAPABILITY_ROLE 环境变量）存在以下根本性缺陷：

根因一：QUENCH_ROLE 由被约束进程自声明，不构成信任边界。任何 Runner 只需
  export QUENCH_ROLE=reviewer 即可自行提权。任务原文以「越权拦截/防欺骗」包装，
  实为「安全剧场」（协作式便利机制，非安全机制）。
根因二：越权判定点错置于 file_scope_guard.py，与文件白名单职责耦合，叠加 50ms 钩子预算。
根因三：以 HTTP 403 描述 stdio/JSON-RPC 的拒绝行为，语汇错位。
根因四：注册期过滤 vs 运行期过滤二义未解，可观测行为不同。

【修改目标】
1. 新建 roles.py，承载单一真相源工具→角色矩阵（TOOL_ROLE_MATRIX），明示「非安全边界」；
   - 模块 docstring 必须写明：本机制为协作式便利隔离，非安全边界；QUENCH_ROLE 可被
     任意进程自行设置，不提供攻击者抵抗；
   - 补全 ADMIN 工具矩阵（禁止 ADMIN 为未定义状态）；
2. server.py 启动期一次性 resolve_role() 并注入 context；仅注册允许的工具（主判定，
   最小信息泄露），dispatch 层再校验一次（纵深防御）；
3. 拒绝路径返回 JSON-RPC 应用错误 code=-32003，错误体 data={tool, role, request_id}；
   禁用 403/PermissionDeniedError 措辞；
4. file_scope_guard.py 仅作二次校验与审计落地；审计写入采用追加+缓冲，禁止 fsync 阻塞；
5. 非法角色值必须 stderr WARNING（fail-loud），不得静默降级；
6. 单进程单角色须在代码与文档中声明为硬前提。
```

from enum import Enum
from typing import Final

class QuenchRole(str, Enum):

# 工具→允许角色 唯一真相源（3.3 文档与单测均从此派生，禁止另立副本）
TOOL_ROLE_MATRIX: Final[dict[str, frozenset[QuenchRole]]] = {
    "dev_reviewer_consult": frozenset({QuenchRole.REVIEWER, QuenchRole.ADMIN}),
    "dev_tasks_checkout":   frozenset({QuenchRole.RUNNER,   QuenchRole.ADMIN}),
    "dev_tasks_status":     frozenset({QuenchRole.RUNNER, QuenchRole.REVIEWER, QuenchRole.ADMIN}),
    # 未列出的工具一律默认拒绝（deny-by-default）
    # TODO: 补全所有工具条目（ADMIN 工具矩阵禁止未定义）

def resolve_role(raw: str | None = None) -> tuple[QuenchRole, str | None]:

    - 未设置 → RUNNER；

    """

```python
DIGEST_FORMAT_VERSION: Final[str] = "quench-review-digest-v1"

def compute_review_digest(
    *,
    workspace_id: str,     # 非路径：git remote URL + commit SHA，或 QUENCH_WORKSPACE_ID
    task_id: str,
    task_revision: str,    # 任务文件内容 SHA-256 或 git blob sha
    findings_bytes: bytes, # 存储原始字节，禁止再序列化
) -> str:
    """SHA-256(version || workspace_id || task_id || task_revision || findings_bytes)。
    docstring 必须写明：本摘要为无密钥内容摘要，仅用于检测意外损坏，不提供防伪造保证。
    """
    h = hashlib.sha256()
    h.update(DIGEST_FORMAT_VERSION.encode())
    for part in (workspace_id, task_id, task_revision):
        h.update(b"\x00"); h.update(part.encode("utf-8"))
    h.update(b"\x00"); h.update(findings_bytes)
    return h.hexdigest()

def verify_review_digest(digest: str, **kwargs) -> bool:
    return hmac.compare_digest(digest, compute_review_digest(**kwargs))
```
