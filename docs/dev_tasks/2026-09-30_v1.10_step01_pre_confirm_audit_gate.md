#### 【缺陷根因与修改目标】
```
【根因分析】
INV-3 Anti-roleplay hard-stop 当前仅是「协议规则」，dev_tasks_confirm 在状态机跃迁时不校验审计是否真实发生过，导致 Runner 可绕过 dev_reviewer_consult 直接 confirm。对抗收敛环（提交/举证 ⇋ 深度审计 ⇋ CLEARED）完全依赖每轮会话的提示词自觉，fresh session 必然衰减，排雷成功无法沉淀为可复现机制。

【修改目标】
1. 将 INV-3 从「协议规则」升级为「可验证契约」：新增 INV-10 Pre-Confirm Audit Gate 规范与 Phase 2.5 操作时序（Plan A 语义层）；
2. 在 project_config.py 与 quench_stack.yaml 引入 AuditGateConfig，为 Tier-1 受管路径提供可选、非死锁、可旁路的物理硬门禁（默认 enabled: false，向后兼容）；
3. 实现任务内容哈希绑定（_compute_task_content_hash），防范篡改后的陈旧复用；
4. 在 dev_tasks_confirm 入口前置 _check_audit_gate，在同一 filelock 临界区内校验有效 CLEARED，消除 TOCTOU 竞争；
5. 提供会话级逃生舱（QUENCH_AUDIT_BYPASS）以及 on_degraded: "warn" 防离线死锁保障。
```

#### 【目标签名与类型契约】
```
# project_config.py
class AuditGateConfig(BaseModel):
    enabled: bool = False                      # 全局开关（默认关闭，opt-in）
    scope: Literal["managed_paths", "all"] = "managed_paths"
    require_marker: str = "CLEARED"            # audit log 必需裁决标志
    audit_log_dir: str = ".agents/logs/reviewer"
    max_age_minutes: int = 120                 # CLEARED 时效窗口
    bind_content_hash: bool = True             # 绑定任务内容哈希（防陈旧复用）
    on_degraded: Literal["warn", "block", "require_human"] = "warn"
    bypass_env: str = "QUENCH_AUDIT_BYPASS"    # 会话旁路环境变量名

class AuditGateResult(TypedDict):
    allowed: bool
    reason: str
    marker: Optional[str]
    audit_ref: Optional[str]

def _check_audit_gate(workspace_root: str, task: TaskItem, config: QuenchStackConfig, session_id: Optional[str]) -> AuditGateResult: ...
def _compute_task_content_hash(task: TaskItem) -> str: ...
```

#### 【分步改造指引】
1. 在 project_config.py 中新增 AuditGateConfig 数据模型并挂载至 QuenchStackConfig.audit_gate（缺省 enabled=False，100% 保证存量任务兼容）；
2. 实现 _compute_task_content_hash(task)，剥离状态 Emoji 与尾部空白后生成 sha256 摘要；
3. 实现 _check_audit_gate(...)，按序执行：① enabled 判断 -> ② 受管路径判断 -> ③ 环境变量旁路判断 -> ④ 读取最新审计日志比对 CLEARED 标志与内容哈希 -> ⑤ 降级兜底依 on_degraded 放行并告警；
4. 在 server.py 的 dev_tasks_confirm 入口处、同一跨进程 filelock 临界区内挂载门禁检查，未通过时阻断流转并返回明确的结构化指引；
5. 在 dev-tasks-discipline.md 增设 §Phase 2.5 审计规范与 INV-10 不变式，并在 AGENTS.md 路由卡追加索引；
6. 编写 test_audit_gate.py，覆盖门禁默认关闭兼容、有效 CLEARED 放行、哈希不匹配拦截、降级 warn 放行、环境变量旁路等完整测试套件。

#### 【防御与边缘校验】
离线死锁红线：on_degraded 默认必须为 warn，Reviewer 不可用时放行但提示，绝不静默死锁
陈旧复用防御：bind_content_hash=True 时，任务文本改动导致哈希不匹配一律判定未审计
TOCTOU 防御：审计读取与任务状态跃迁必须处于同一 filelock 临界区内
50ms 钩子预算零侵入：门禁只在工具调用期执行，绝对不引入新的 PreToolUse 拦截
路径兼容性：使用 to_workspace_relative_path / os.path 兼容 Windows 反斜杠
