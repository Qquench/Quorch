#### 【缺陷根因与修改目标】
```
atomic_replace_manifest 中单条记录超限分支为空操作 (pass)，声明的 MAX_RECORD_BYTES 物理上限防护实际失效，异常/超长任务可导致清单无界膨胀。同时，分代归档一旦实施将牵动 Fencing Token 单调性与 reconcile_workspace 权威判定，须在实现前冻结架构契约以防返工。修改目标：修复空操作分支为 Fail-Closed 熔断异常，增加 ManifestMetrics 纯函数度量指标，并冻结分代压缩四项架构不变量。
```

#### 【目标签名与类型契约】
```
ManifestRecordOverflowError(ManifestIntegrityError), ManifestMetrics(record_count: int, total_bytes: int, max_record_bytes: int), compute_manifest_metrics(manifest: Manifest) -> ManifestMetrics
```

#### 【分步改造指引】
1. 在 manifest.py 中定义 ManifestRecordOverflowError 与 ManifestMetrics / compute_manifest_metrics 纯函数
2. 在 atomic_replace_manifest 中将 pass 替换为 raise ManifestRecordOverflowError，在任何磁盘写操作之前 Fail-Closed 阻断
3. 编写 docs/architecture/manifest_compaction_contract.md 固化分代归档四大铁律
4. 编写 plugins/quench-dev-tasks/server/tests/test_manifest_bounds.py 覆盖超长阻断原子性、CJK 多字节边界与 metrics 精确度

#### 【防御与边缘校验】
- 溢出校验必须严格基于 UTF-8 字节长度 (len(s.encode('utf-8')))，防止 CJK 多字节字符截断撕裂
- 严禁任何形式的静默截断 (Silent Truncation)，截断丢失 token/generation 将破坏 Fencing 安全网
- 异常必须在创建临时文件或写盘之前抛出，确保原子性 (Manifest 磁盘文件保持原样)
- compute_manifest_metrics 必须为纯函数，禁止对 manifest 对象产生任何副作用
