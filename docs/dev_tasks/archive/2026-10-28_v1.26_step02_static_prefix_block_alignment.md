#### 【缺陷根因与修改目标】
```
动机（终审确认）：现有 assemble_consultation_prompt 构造的 static_system_prefix 若长度非 block 边界倍数，Provider 侧 block 对齐候选区存在命中率折扣。
本任务以【确定性字节级近似的 LF 填充】（非真实 token 边界，不引入 tokenizer 依赖）提升 block 对齐命中率，同时严禁破坏以下已存在的三条硬契约：
  (a) AssembledPrompt 保持 frozen=True, slots=True，且构造函数入参 static_system_prefix 与 stable_prefix 属性严格等价（现有 test_prompt_cache_stability.py:78-87 硬锁）；
  (b) prefix_hash 的派生源继续为「原始未填充静态前缀 + 模式锚点」，填充绝不进入哈希输入；
  (c) code_context_block / dynamic_tail 在填充前后逐字节恒等。

【终审裁定 — 设计选择（强制 Design B 旁路填充）】：
  - AssembledPrompt 构造函数契约完全不变（现有测试 0 回归）。
  - 在 assemble_consultation_prompt 内部生成本地变量 padded_static_prefix = align_static_prefix_to_block(raw_static_prefix)，
    仅用于构造「Provider wire 输出」使用的 AssembledPrompt 实例的 static_system_prefix 字段；
  - 但 prefix_hash 仍由 raw_static_prefix 计算；
  - 因此现有 test_assembled_prompt_slots_structure 直接构造 AssembledPrompt(...) 的用例完全不受影响。

【终审裁定 — 填充字符集与边界】：
  - 强制使用 LF (\n) 单一字符，严禁 \r、严禁空格、严禁 \r\n。
  - 填充公式：若 len(prefix) == 0 -> return ""  （空前缀不得填充，返回空串）；
            若 len(prefix) % block_bytes == 0 -> return prefix  （已对齐，幂等返回）；
            否则 -> return prefix + "\n" * (block_bytes - (len(prefix) % block_bytes))
  - block_bytes 默认 64（显式常量名 STATIC_PREFIX_BLOCK_BYTES: Final[int] = 64）。
```

#### 【目标签名与类型契约】
```
1. 精度等级声明：确定性字节级近似 block 对齐；不声称真实 token 精确性；不引入第三方 tokenizer 依赖。
2. 纯函数签名：
     STATIC_PREFIX_BLOCK_BYTES: Final[int] = 64
     def align_static_prefix_to_block(prefix: str, block_bytes: int = STATIC_PREFIX_BLOCK_BYTES) -> str
   - 输出严格由入参决定（相同入参 -> 字节恒等输出）；
   - 纯函数，无 IO、无全局状态、无缓存；
   - 严禁按总 prompt 长度动态取模（只依赖 prefix 自身）。
3. 边界契约：
   - align_static_prefix_to_block("") == ""            （空前缀返回空串，不填充）；
   - align_static_prefix_to_block(prefix) 当 len(prefix) % block_bytes == 0 时恒等返回原串（幂等）；
   - 返回值中严禁出现 "\r" 字节；仅允许 "\n" 作为填充字符。
4. prefix_hash 冻结契约（禁止破坏）：
   - prefix_hash = compute_prompt_hash(<与现有实现完全相同的入参形式>, workspace_root)；
   - 填充绝不进入 prefix_hash 输入；
   - 现有 test_prompt_cache_stability.py 中所有 prefix_hash 相关断言 0 回归。
5. AssembledPrompt 契约不变：
   - frozen=True, slots=True；
   - static_system_prefix / stable_prefix / code_context_block / dynamic_query / dynamic_tail / mode_anchor 现有语义不重定义；
   - 构造函数现有测试 0 回归（padding 在 assemble_consultation_prompt 内部应用，不在 __init__ 内）。
```

#### 【防御与边缘校验】
- 空前缀：返回空串（不引入 64 字节填充）；
- 纯空格前缀：正常按长度对齐；
- 已对齐前缀：幂等返回原串；
- block_bytes <= 0：抛出 ValueError；
- UTF-8 多字节字符：Python 字符级近似，断言 "\r" not in result；
- hash 隔离：填充绝不进入 compute_prompt_hash 入参；
- 段落隔离：context_block 与 dynamic_tail 字节恒等。
