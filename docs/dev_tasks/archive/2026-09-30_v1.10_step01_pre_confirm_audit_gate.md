**确定性守卫序阶梯（R11 互斥完备版，首次命中即终局）：**
```
0   enabled is False                                                  → disabled               (allow)
1   scope == "managed_paths" ∧ not any(_managed_path_matches(f, managed_paths) for f in task_scoped_files) → not_managed_scope (allow)
2   session Tier-2 bypass 有效                                        → session_bypass_active  (allow)
3   log 不存在                                                        → log_missing            [on_degraded]
4   log I/O 读取/解码失败（非截断所致）                               → log_unparsable         [on_degraded]
5   命中 canonical artifact_ref ∧ ts 可解析 ∧ record_ts ≤ now + tolerance
    ∧ _freshness_ok is True ∧ (¬require_undegraded ∨ 未 degraded)      → matched                (allow)
6   命中 ∧ ts 可解析 ∧ record_ts ≤ now + tolerance ∧ _freshness_ok is False → record_stale      [on_missing_record]
7   命中 ∧ require_undegraded ∧ 有 degraded_reason ∧ ts 可解析
    ∧ record_ts ≤ now + tolerance ∧ _freshness_ok is True             → record_degraded        [on_degraded]
8   命中 ∧ (ts 不可解析 ∨ 未完成 tz 归一化 ∨ record_ts > now + tolerance) → record_timestamp_invalid [on_degraded]
    ▲ step 8 前置：tz 归一化先于 timedelta 运算；naive TS 直入本步，严禁滑入末尾 internal_error。
9   truncated（size > max_tail_bytes）且可读尾部无匹配                 → tail_window_exhausted  [tail_window_exhausted_policy]
10  其余（可读、未截断、确无匹配记录）                                → no_matching_record     [on_missing_record]
-   任意未捕获异常                                                     → internal_error         [on_internal_error]
```
**锁内重校验契约（R11）**：`dev_tasks_confirm` 在门禁 `allowed=True` 后获取 manifest 锁；持锁段内必须重算 `canonical_artifact_ref` 并断言任务仍为 `⬜ 待确认`；任一不符则以 **`precondition_changed`**（fail-closed 阻断，严格隔离 allow 语义）中止，**manifest 零写入**。
