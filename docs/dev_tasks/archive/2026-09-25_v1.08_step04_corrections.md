#### 【缺陷根因与修改目标】
```
【根因分析】
1. 【C-1 租约永久僵死 / DoS】：acquire_or_probe 仅调用 probe_peer，完全不读取盘上 updated_at 做超时判定；
   而 probe_peer 在遇到 PID 被无关进程复用（Windows svchost / 容器 pid 回绕）或持锁进程被 SIGSTOP 挂起时，
   保守返回 takeover_allowed=False。导致全工作区租约永久锁死，除人工 rm 外毫无自愈手段。
2. 【C-2 / C-A 心跳锁竞争与 touch() 字符串真值陷阱】：
   - acquire_or_probe 与 touch() 各自创建独立的 FileLock 实例，导致同进程自锁；
   - 若 touch() 返回字符串 Literal，在 Python 中 bool("lost") 恒为 True，现存 `if not guard.touch(): break`
     永不触发退出，夺权后旧持有者心跳线程无法 fail-stop，导致双写者撕裂日志。
3. 【C-B 锁文件本地化互斥破坏隐患】：若将 lock_root 单独迁往 LOCALAPPDATA 等用户本地路径，
   跨用户/跨容器/跨机进程将各自持有本地锁，导致物理互斥彻底失效；
   因此锁文件必须与 workspace.lease.json 保持严格同目录，并对不支持 flock 的网络/同步盘实行 fail-closed 探测。
4. 【C-4 任意文件删除隐患】：破坏性 GC 直接消费 JobRecord.log_path 绝对路径，未校验 realpath 包含性与白名单正则；
   若跨环境映射（WSL）或外部伪造 job JSON，unlink 存在越界删除工作区外任意文件的风险。
5. 【C-6 顺序不变量未强制】：reconcile_orphans 启动对账未被强制约束在 WorkspaceLeaseGuard.is_held() 下，
   若先于租约获取执行，会误杀他进程正常在途任务。
6. 【H-B / H-D / H-1 契约规范与 fencing 缺失】：
   - workspace_lease.py.__init__ 现存断言 assert 在 python -O 下被剥离导致入参校验失效；
   - JobRecord 持久化落盘路径未强制校验 guard.generation，导致 fencing 成为死字段。

【修改目标】
1. 建立「心跳陈旧度为主 + 进程探针为辅」的超时夺权模型：stale := (now_utc - updated_at) > lease_ttl_s * 3；
   takeover_allowed = stale and not (probe_confident and is_alive)，夺权必须递增 fencing generation。
2. 消除真值陷阱：LeaseTouchOutcome 改为 enum.Enum 派生（RENEWED / LOST / CONTENTION）；
   Heartbeat 线程显式比对 `outcome == LeaseTouchOutcome.LOST`；禁止全仓对 touch() 进行布尔隐式真值判定。
3. 同目录同频互斥与 fail-closed：锁文件与 lease 文件均置于 .agents/ 同目录下；
   探测到不支持 flock 的网络文件系统时，启动期 fail-closed 拒绝启动或强制只读。
4. 心跳 fail-stop 与可中断退避：touch() 遭遇 CONTENTION 时进行指数退避，退避使用 stop_event.wait(t) 可中断等待；
   遇到 LOST 时立即退出心跳线程并触发 fail-stop；全仓禁止 except: pass。
5. is_held() 强制复核心跳新鲜度：self._is_held and (monotonic() - self._last_touch_monotonic) < lease_ttl_s * 0.8。
6. 统一破坏性门禁：新增 destructive_context() 上下文管理器，收敛 reconcile、reaper、gc、unlink。
7. 破坏性路径三重防御：强制 realpath 位于 <workspace>/.agents/logs/ 下、匹配白名单正则、校验 registry key。
8. 去 assert 化：workspace_lease.py 所有断言改为显式 raise ValueError，确保 python -O 下校验不脱保。
9. 落盘门禁：在持久化写路径前置校验 guard.generation，失配立即抛出 LeaseGenerationLostError。
```
