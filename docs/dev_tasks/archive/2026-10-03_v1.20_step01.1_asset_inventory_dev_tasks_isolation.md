#### 【缺陷根因与修改目标】
```
RC-INV-NOISE (Medium): scripts/asset_inventory.py 的 CONSUMER_SCAN_ROOTS / DOC_ROOT_RELS 均含顶层 "docs"，其子路径 docs/dev_tasks/ 未排除。当任务单（本 step 及后续 step）的【涉及文件】或【目标签名】提及代码符号（如 FIELD_ALIASES）时，扫描器将其误判为文档消费者，doc_refs 由 NONE 变 1，符号被剔出移除候选集，触发 --check 虚假漂移（如 100 -> 99）。

附加根因：docs/dev_tasks/ 与 docs/dev_tasks/archive/ 同侧被扫描，使 cli.py::cmd_archive 的归档动作成为图谱的非确定性来源（任务归档即翻转门禁）。

目标：
1. 引入 DOC_NON_CONSUMER_PREFIXES = ("docs/dev_tasks",)，以【目录分量语义】排除任务单与任务归档噪音；
2. 使图谱对任务单增删/归档完全免疫，--check 恢复确定性绝对绿态；
3. 建立 DOC_NON_CONSUMER_PREFIXES ⊆ DOC_ROOT_RELS 的机械不变量，防止双策略静默失配。
```

#### 【目标签名与类型契约】
```

  # 契约：每项以 POSIX 相对路径表达，解释语义为【目录分量前缀】，非裸字符串前缀
  _is_non_consumer_doc(rel_posix: str) -> bool
  # 纯函数：rel_posix 已由 as_posix() 规范化；以 PurePosixPath 分量判定
  #   p == prefix  or  prefix in p.parents
  # 禁用 p.startswith(prefix) 裸前缀写法（防误吞 docs/dev_tasks_*）
  scan_doc_references(...): 收集文档符号引用前调用 _is_non_consumer_doc 过滤

plugins/quench-dev-tasks/server/tests/test_asset_inventory.py:
```
