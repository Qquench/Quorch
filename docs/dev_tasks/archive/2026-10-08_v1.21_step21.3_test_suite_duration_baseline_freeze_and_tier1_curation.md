#### 【防御与边缘校验】
- **统计确定性**：`std_dev = statistics.stdev`（ddof=1），契约测试以解析夹具锁死；`mean == 0.0 → cv = 0.0`（纯函数），但 `mean <= 0 or min_duration <= 0` 在 `run_*_benchmark` 侧一律 fail-closed。
- **反绕过**：`--check` 下 `iterations < MEASURED_ITERATIONS` 直接非零退出，杜绝「降采样关闭方差门禁」。
- **测量自递归物理隔离（双层）**：① 进程内哨兵 `QUENCH_TEST_DURATION_BENCH_ACTIVE` + 契约测试导入期 skip（纯函数可测）；② `run_tier2_benchmark` 强制 `--deselect` 契约测试文件。任何一层缺失即视为未完成。
- **argv 一致性**：计时 argv 与 `test_tier1_fast_budget_execution` 逐元素一致；严禁对计时路径使用 `NEUTRALIZE_ARGS`（`-o addopts=` / `-p no:cacheprovider`）。
- **有界重测与轮次返回语义**：CV 越界仅在 `allow_retry=True` 时允许 `MAX_CV_RETRY_ROUNDS = 1` 轮重测（重新预热 + 重新采样），开销上界确定；返回最后一次实际执行轮 metrics；两轮皆越界才红。
- **超时与异常 fail-closed**：子进程非零退出、超时（Tier-1 15s / Tier-2 300s）、输出解析失败（执行数 <= 0 或摘要缺失）、样本不足、均值/最小耗时非正，全部立即报红，严禁假绿。
- **环境物理净化**：复用 `sanitized_env`，过滤 `PYTEST_*` 与 `PYTEST_XDIST_*` 前缀。
- **零外部依赖与跨平台**：仅标准库（math, statistics, subprocess, argparse, json, time, re）；子进程 `encoding="utf-8", errors="replace"`；stderr 输出做 ascii-safe fallback。
- **★并发不变量硬门禁★ 绝对隔离**：严禁在 Tier-1 引入任何匹配 `state_machine or reclaim_cas or workspace_lease` 的用例；本步不触碰 H 内容，H ∩ Tier-1 = ∅ 不变。
- **契约测试成本严格封顶**：真实锚点（`allow_retry=False`）4 次子进程 + 归属断言 1 次 + deselect 生效验证 1 次 ⇒ 本文件子进程总数 ≤ 6（实际 6），且绝对不包含任何真实 Tier-2 执行。
- **库层假绿封堵（R-A）**：`run_tier1_benchmark` 对 `iterations < 2`（等价 `len(durations) < 2`）在**库层**即 fail-closed，不依赖 CLI 守卫；`calculate_metrics` 的 `len==1 → cv=0.0` 纯函数契约保持不变；断言直调 `run_tier1_benchmark(iterations=1)` 返回 `ok is False`。
- **Tier-2 基线口径与里程碑关系**：`run_tier2_benchmark` 报告值为工程套件(excl harness) 基线；权威里程碑上限一律以全量 `pytest -q`（含 harness）为准。
- **R2 回退策略**：若真仓端到端锚点在特定 CI 共享机器出现极端耗时抖动，可最小化采样，但真仓端到端锚点绝对不得降为 0 且回退下限 `iterations >= 2`（满足 TP-2 真仓锚点律与 R-A 防假绿）。
