## 2. 自动化门禁项 (Automated Verification)

### 场景 4: 降级态与异常断言 (Degraded Fallback Card)
- **断言目标**: 当 Reviewer 引擎未配置或模型不可用时，系统平稳降级，返回 `findings == ""` 的结构化卡片，绝不发生长轮询挂死或未捕获崩溃。
- **关联测试**:
  - `plugins/quench-dev-tasks/server/tests/test_anti_roleplay_discipline_contract.py`
  - `plugins/quench-dev-tasks/server/tests/test_reviewer_jobs_watch.py` (`test_watch_short_circuit_on_terminal`)
- **执行命令**:
  ```bash
  python -m pytest plugins/quench-dev-tasks/server/tests/test_anti_roleplay_discipline_contract.py -q
  ```

### 场景 5: INV-4 Stdio Channel 纯净性 (Protocol Channel Purity)
- **断言目标**: 服务端进程生命周期内所有 `print()` 严禁流入 `sys.stdout`，所有进度通过 FastMCP `report_progress` 协议通道或 RotatingFileSink (`.log`) 写入。
- **关联测试**:
  - `plugins/quench-dev-tasks/server/tests/test_anti_roleplay_discipline_contract.py` (`test_stdio_purity`)
  - `scripts/check_no_api_bypass.py`
- **执行命令**:
  ```bash
  python -m pytest plugins/quench-dev-tasks/server/tests/test_anti_roleplay_discipline_contract.py -k "stdio or purity" -q
  ```

## 3. 人工走查 Checklist (Manual Inspection)

### 场景 1: VS Code 环境走查 (Claude Dev / Continue / MCP Inspector)
- [ ] 启动 MCP Inspector 或打开 VS Code 连接本地 Quench FastMCP 服务：
  ```bash
  npx @modelcontextprotocol/inspector python plugins/quench-dev-tasks/server/server.py
  ```
- [ ] 触发 `dev_reviewer_submit` 提交异步咨询任务，记录返回的 `job_id`。
- [ ] 调用 `dev_reviewer_poll(job_id=..., wait_max_s=20)`，观察客户端控制台或进度条：
  - [ ] 界面显示平滑的进度消息通知（格式：`Thinking (<phase>) · <m>m <s>s · idle <idle_s>s`，单行 ≤ 120 字符）。
  - [ ] 消息没有产生数千字符的 JSON 对象刷屏。
  - [ ] 任务终态完成时，进度通知停止，工具直接返回完整终态结果字典。

### 场景 2: Antigravity IDE 原生环境走查
- [ ] 在 Antigravity IDE 会话中触发架构审查或执行任务流转。
- [ ] 观察底栏 / 任务窗格中的微动动画或任务卡片：
  - [ ] 非终态轮询期间，每轮 `wait_max_s=20s` 内正常接收到进度跳动，未触发 IDE 客户端的默认 30s 请求超时断开。
  - [ ] 终态达成后，卡片立即收敛为最终判定，无闪烁。

### 场景 3: Antigravity App 5 轮长轮询不超时走查 (Long-Poll Resilience)
- [ ] 模拟或触发长达 100s 的深度推演任务（跨越 5 轮 `wait_max_s=20` 轮询）。
- [ ] 走查项验证：
  - [ ] 第 1 轮长轮询挂起等待约 20s，返回 V2 非终态字典（包含 `elapsed_s`、`retry_after_seconds`、`log_ref` 6 大字段）。
  - [ ] 客户端顺畅衔接发起第 2、3、4、5 轮轮询，全程无网络断连或丢包。
  - [ ] 5 轮轮询总计过程中无任何中间非终态数据落盘写入（零写盘 W10）。
  - [ ] 最终任务完成顺利取得 `state == "COMPLETED"`。
