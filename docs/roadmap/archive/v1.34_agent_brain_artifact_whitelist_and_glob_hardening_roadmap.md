## 1. Executive Summary & Root Cause (背景与根因)

### 1.1 问题背景 (Problem Statement)
在 IDE 宿主环境（如 Antigravity）中，Agent 在执行规划、走查汇报、架构总结或浏览器/草稿辅助任务时，会向会话专属的运行期 `brain/<conversation-id>/` 目录写入 Markdown 制品文件（如 `walkthrough.md`、`implementation_plan.md`、`task.md` 等）以及 `scratch/**`、`browser_sandbox/**` 临时文件。
由于 `brain/` 目录位于宿主用户数据目录（`<appDataDir>/brain/<conversation-id>/...`），物理上处于当前代码仓库 `workspace_root` 之外（在 Windows 环境下通常还跨越盘符，例如 `C:\Users\...\brain\...` 与 `D:\Work\...`），当前 `PreToolUse` 钩子（`file_scope_guard.py`）与配置边界引擎（`project_config.py`）会将其判定为「跨出工作区边界的未纳管生产代码」，无论当前处于无任务空载状态（触发 `【未纳管代码修改确认】`）还是有活跃任务 `🔨 执行中` 状态（触发 `[Out-of-Scope File Modification Warning / 范围外修改拦截]`），均会弹出 `ASK_MODAL`（`force_ask`）阻塞正常制品写入。

### 1.2 根因解构 (Root Cause Analysis)
1. **工作区外路径在 `is_path_governed` 中无条件短路为受管代码**：
   - `project_config.py::QuenchStackConfig.is_path_governed` 在检查 `unmanaged_paths` 与 `DEFAULT_UNMANAGED_EXTENSIONS`（如 `.md`）之前，通过 `os.path.commonpath([real_target, real_root])` 进行越界防御，对所有位于 `workspace_root` 之外或跨驱动器的路径一律返回 `True`（受管生产代码）。
   - 同时，`file_scope_guard.py::resolve_realpath_under` 对工作区外路径返回 `None`，使 `effective_target` 退回原始路径字符串并进入受管代码拦截分支。
2. **缺乏针对 Agent 运行期 `brain/` 制品沙箱的内置与默认快速通道白名单**：
   - `.agents/quench_stack.yaml` 与 `plugins/quench-dev-tasks/templates/quench_stack.yaml` 中的 `fast_track_rules.allow_untracked_patterns` 默认为空列表 `[]`；
   - `file_scope_guard.py` 未内置针对 `/brain/<session_id>/` 运行期制品路径的默认白名单规则。
3. **多段递归 Glob（`**`）在跨盘符/外部路径与零中间层级下匹配失灵**：
   - `file_scope_guard.py::matches_pattern` 与 `project_config.py::_match_glob` 在处理 `norm_pattern.endswith("/**")` 时，仅截取 `prefix = norm_pattern[:-3].strip("/")`。当模式为 `**/brain/**` 时，`prefix` 保留了前导 `**/brain`，导致 `f"/{prefix}/" in f"/{rel_path}/"` 查找字面量 `"/**/brain/"` 恒为 `False`；
   - 对于 `**/brain/**/*.md` 或 `frontend/src/**/*.vue` 等含多处 `**` 的模式，标准库 `fnmatch.fnmatch` 要求每个 `**/` 两侧必须存在物理 `/` 分隔符，导致：
     - 当路径位于 `brain/<file>.md`（0 个中间子目录）时无法命中 `**/brain/**/*.md`；
     - 当相对路径以 `brain/...` 开头（无前导 `/`）时无法命中 `**/brain/**`。

## 2. Objectives & Non-Goals (目标与非目标)

### 2.1 核心目标 (Goals)
1. **内置 Agent `brain/` 运行期制品白名单与防逃逸物理校验（`file_scope_guard.py`）**：
   - 定义厂商中立的内置白名单常量 `DEFAULT_AGENT_BRAIN_PATTERNS: Tuple[str, ...] = ("**/brain/**/*.md", "**/brain/**/scratch/**", "**/brain/**/browser_sandbox/**")`；
   - 抽取物理路径解析原语 `resolve_physical_path(workspace_root, target)`，对尚未创建的目标文件递归解析其已存在祖先目录的 `realpath`，彻底消解软链接、junction 及 `..` 相对路径穿越（严防 `.../brain/conv-1/../../evil.py` 借道绕过）；
   - 新增 `is_agent_brain_artifact(target_file, workspace_root)` 并在 `is_whitelist_matched` 中融合 `DEFAULT_AGENT_BRAIN_PATTERNS` 与 `config.get_fast_track_patterns()`，确保无论是否存在 `🔨 执行中` 任务，也无论下游项目是否已更新 `quench_stack.yaml`，Agent 向 `brain/<session_id>/` 写入 `.md` 制品及 `scratch/`、`browser_sandbox/` 文件均自动命中白名单放行（`decision="allow"`）。
2. **路径段感知（Segment-Aware）的多段 `**` 递归 Glob 引擎加固（`file_scope_guard.py` & `project_config.py`）**：
   - 在 `matches_pattern` 与 `_match_glob` 中实现基于路径段切分的 `**` 递归匹配器（`_match_segmented_glob`），支持 `**` 匹配 **0 个或多个**完整路径段，单星号 `*` 在单段内按 `fnmatchcase` 匹配；
   - 确保 `**/brain/**/*.md`、`**/brain/**`、`brain/**/*.md`、`frontend/src/**/*.vue` 等模式在工作区内相对路径、跨盘符外部绝对路径、0 层或多层中间子目录下均精确匹配，且严格按目录段边界隔离（绝不误放行 `my_brain_repo/README.md` 或 `brain/evil.py`）。
3. **本仓配置、项目模板与架构文档同步（`.agents/quench_stack.yaml`、`templates/quench_stack.yaml`、`docs/`）**：
   - 在 `.agents/quench_stack.yaml` 与 `plugins/quench-dev-tasks/templates/quench_stack.yaml` 的 `fast_track_rules.allow_untracked_patterns` 中显式加入 `**/brain/**/*.md`、`**/brain/**/scratch/**`、`**/brain/**/browser_sandbox/**`；
   - 同步更新 `docs/configuration.md` 与 `docs/architecture/README.md` 的快速通道白名单说明。
4. **严守安全边界与核心架构不变量**：
   - 100% 保持普通工作区外路径（如 `../../etc/passwd`、`../outside_project/evil.py`、`D:\OtherRepo\README.md`）以及任务目录逃逸（`docs/dev_tasks/../../outside.md` -> `realpath_escape`）的拦截契约不退化；
   - 100% 保持 `_DEFAULT_FAST_TRACK_PATCH` 的 v0->v1 配置自动迁移单测兼容；
   - 严格遵守 **INV-5**（核心模块零厂商字面量）、`file_scope_guard.py` 零状态 Emoji 字面量以及 `<50ms` 子进程轻量导入隔离门禁。

### 2.2 显式非目标 (Non-Goals)
- 不放开任意工作区外路径的写入权限（仅豁免命中 `brain` 制品白名单模式或用户显式声明在 `allow_untracked_patterns` 中的受控模式）；
- 不弱化 `docs/dev_tasks/` 任务单目录的 `realpath_escape` 硬拒绝（`deny`）防线与状态篡改守卫。

## 3. Architecture & Core Specifications (架构与契约规约)

### 3.1 内置 Agent Brain 制品白名单常量与判定契约 (`file_scope_guard.py`)
```python
DEFAULT_AGENT_BRAIN_PATTERNS: Tuple[str, ...] = (
    "**/brain/**/*.md",
    "**/brain/**/scratch/**",
    "**/brain/**/browser_sandbox/**",

def resolve_physical_path(workspace_root: str, target: str) -> Optional[str]:
    """解析目标文件的物理绝对路径（消解 symlink、junction 与 .. 相对路径，支持文件尚未创建时回溯祖先目录 realpath）。"""
    ...

def is_agent_brain_artifact(target_file: str, workspace_root: str) -> bool:
    """判定目标文件是否属于 IDE/Agent 运行期 brain 会话制品或沙箱临时文件（已做物理路径消解防逃逸）。"""
    ...
```

### 3.2 路径段感知的多段 `**` Glob 匹配契约 (`_match_segmented_glob`)
- 将目标路径与模式统一规范化为 `/` 分隔的小写路径段序列 `path_parts` 与 `pat_parts`（折叠连续的 `"**"` 段）；
- `"**"` 段可匹配 0 个、1 个或多个连续的 `path_parts` 段；
- 非 `"**"` 段通过 `fnmatch.fnmatchcase(path_part, pat_part)` 精确匹配单个路径段；
- 对于 `norm_pattern.endswith("/**")`，剥离前导 `"**/"` 后再做目录段边界包含判定，彻底修复 `**/brain/**` 前导通配符截断缺陷。
