### 2.1 实例化门禁（Instantiation Gate）—— 三分支完备模型

step21.0 完成后，**必须**执行【证据消费实例化】三分支判决：
1. **EVIDENCED 分支**：存在具体 Delta Report 条目支撑 $\to$ 实例化为 `CONFIRMED` 六字段 DevTask（绑定预算与涉及文件白名单，遵 G-OE'）；
2. **NULL_INPUT 分支**：输入为空集（如 `Emerged: 0`） $\to$ 裁决为 `COLLAPSED`，折叠进前序步骤，但折叠不等于豁免——必须物化三断言门禁（presence + emptiness + totality）方可视为闭合，**禁止制造空跑生产任务**；
3. **UNSUPPORTED 分支**：无客观 Delta Report 证据支撑 $\to$ 裁决为 `DEFERRED`，降级为 `over_engineering_inventory.md` 远期候选，**严禁反向绑架当前 step**。

### 3.1 G1' 复杂度预算契约
- **输入**：`ToolSurface` MCP 签名快照（已由 step22.4a 生成，针定于 `docs/architecture/tool_surface_snapshot_v122.json`，哈希 `4fa698fe768fe13bcbc875c4857dddd80f06ec3e97cc9ac1755e0c8a58f414b1`）。
- **检测（三条件）**：① 三元组 `(参数 schema + 状态跃迁 + 返回契约)` 去重；② 语义正交性；③ A1–A7 单机公理映射。
- **输出**：违规三元组 → 删除/合并候选，须经 Delta Report 证据授权方可执行；当前 17 工具经 step22.4a 机械去重门禁验证重复签名组为 0。

### 3.2 双 lease 收敛契约（★高风险，携 INV-1 护城河）
- **语义域正交性**：已证明 `manifest_lease`（任务所有权跨进程互斥）与 `workspace_lease`（审查工作区变更互斥）属于不同失效域。
- **永久裁决分支**：**物理消除合并分支，永远 fail-closed 保留双 lease**。
- **允许收敛范围**：仅允许局部消除无害重复非不变量原语（如 norm_path_pure 等纯路径归一化原语、通用错误码、Windows 保留设备名常量等）。
- **硬约束**：任何触及必须 ★并发不变量硬门禁★ 全绿 + C-1/C-2/C-6 不变量不回归。

### 3.3 模块切分/合并契约
- **前置**：import 图无环（step08 已保证，须复核）。
- **不变量边界**：`server.py` 保持 Tier-2 单一网关（A2）；`reviewer_engine.py` 保持唯一 provider egress（INV-9）；`assert_read_only_sandbox` 归口不变（INV-6）。
